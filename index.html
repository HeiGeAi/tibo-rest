      06 · Honesty

      FAQ · 诚实问答

      Is this affiliated with OpenAI?

      No. tibo.rest is an unofficial fan-made lounge. Not affiliated with OpenAI, Anthropic, or AIHOT. “Tibo” refers to Thibault Sottiaux (@thsottiaux) as a community meme — we don’t speak for him.

      Can this see my Codex / ChatGPT Work quota?

      No. Personal balances only appear inside Codex / ChatGPT. This page never asks for logins, cookies, or API tokens. Your prayers and vigil stamp stay in localStorage.

      Where does the reset radar come from?

      Public calendar events from AIHOT via GET /api/v1/codex-resets (CORS open, ETag polling ≥5 min). If the live API is unreachable, we show a shipped snapshot. We do not scrape competitor HTML.

      Do you predict the next reset?

      No. We show confirmed public signals (direct_reset, reset_credit) and how long since the last confirmed global reset. Anything else is lounge banter — not a forecast you should bet on.
